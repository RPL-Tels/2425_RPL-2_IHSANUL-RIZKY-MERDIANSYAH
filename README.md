# Aplikasi Input Berkas Brimen

Seiring berkembangnya teknologi, perbankan menghadapi kebutuhan mendesak untuk beradaptasi dengan inovasi digital guna meningkatkan pelayanan kepada nasabah dan efisiensi operasional. Bank Rakyat Indonesia (BRI) sebagai salah satu bank terbesar di Indonesia turut mendukung digitalisasi proses internal dan pelayanan kepada nasabah.

## 📌 Latar Belakang

Sebelumnya, proses pengumpulan dan penyimpanan berkas dilakukan secara manual, yang menimbulkan berbagai tantangan seperti:

- Keterlambatan proses input data
- Risiko kesalahan input atau kehilangan data
- Kesulitan saat pencarian kembali dokumen

Untuk mengatasi permasalahan tersebut, dikembangkan **Aplikasi Input Berkas Brimen** berbasis website. Sistem ini bertujuan untuk menyederhanakan proses input, penyimpanan, dan pencarian data berkas secara digital.

## 🎯 Tujuan

Aplikasi ini dikembangkan dengan tujuan untuk:

- Memudahkan pegawai Bank BRI dalam menginput dan mengakses data berkas secara cepat dan efisien
- Meningkatkan produktivitas dan kecepatan pelayanan bank
- Mendukung proses digitalisasi internal di lingkungan Bank BRI

## ⚙️ Teknologi yang Digunakan

- **Visual Studio Code** v1.85.2
- **Node.js** sebagai back-end
- **EJS** sebagai templating engine
- **MySQL** sebagai sistem manajemen basis data

## 🖥️ Fitur Utama

- Input data berkas nasabah
- Upload file pendukung (jaminan, kuitansi, dsb.)
- Pencarian data secara cepat
- Penyimpanan data secara efisien di database
- Antarmuka berbasis web yang mudah digunakan
